# 提示词：切开单页

你拿到的是 saltline 的 `index.html`，一个可玩的浏览器射击页，不是原生包，也没有源码地图。不要通读整文件。按下面的顺序切，每一步只报告锚点和字节范围。

1. 数 `<script` 标签。现在应是两段。第一段从 `(function () {` 开始，里面有明文 `mason.cache.l2`、`mason.cache.l3`、`saltline.settings.v1`。第二段从 `(()=>{var _M=Object.defineProperty` 开始，这是 Three.js 和游戏压在一起的包。
2. 壳层是两段 script 之外的 HTML 和 `<style>`。界面节点以 `#app`、`#view`、`#ui`、`#boot` 为准。`#ui` 的菜单是大包在运行时写进去的，不在静态 HTML 里。
3. 大包里禁止按函数名复原工程目录。只允许用这些不会被压缩掉的字符串当锚点：`正在启动渲染器`、`正在布置集装箱`、`mason九式突击步枪`、`甲号中继`、`Slash:"fire"`、`window.__ready`。
4. 输出一张表：区域、起始锚点、大约长度、里面有什么。没有锚点的句子删掉。

不保证短变量名和打包前一致。`v_`、`mM`、`Hg` 这种名字只是当前位置，下次压缩会变。
