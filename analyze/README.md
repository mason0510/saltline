# analyze

把 `index.html` 拆回可核对的系统说明。材料只有这一份页面，没有打包前的工程。

## 算法：锚点切开

- 保证：每条结论都能指回 `index.html` 或 `sw.js` 里的唯一字符串。找不到就写「未证实」，不补作者意图。
- 输入：当前仓库的 `index.html`、`sw.js`。
- 触发：按下面顺序，一次只把一个提示词和页面交给模型。不要把 1.4MB 整页当散文读。
- 停止：壳层、启动、输入、任务四张卡都写完，且每张卡至少有一个锚点。
- 不保证：还原出打包前的文件名、注释或最初变量名。大包里的短名字是压缩后的。
