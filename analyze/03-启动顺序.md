# 提示词：启动顺序

在第二段 script 里搜索 `async function QC` 和 `正在启动渲染器`。boot 文案是按顺序 `Nr(...)` 出来的。请按出现顺序抄下每句文案，以及它后面注册到 `t` 上的字段名。当前文件里的顺序是：

1. `正在启动渲染器` → `render`
2. `正在生成涂装、锈迹与雨水` → `mats`，然后 `physics`、`props`
3. `正在布置集装箱` → `level`
4. `正在架设起重机` → `backdrop`
5. `正在生成港区地面` → `ground`
6. `正在加载弹道与烟雾` → `fx`，然后 `audio`、`player`、`combat`
7. `正在检查mason制式步枪` → `weapon`
8. `正在启动港区主控` → `enemies`，然后 `hud`、`game`

循环在 `setAnimationLoop`。`window.__ready` 在第二帧之后才变成 `true`。`#boot` 加上 `done` 后约 700ms 隐藏。

查询参数从 `URLSearchParams(location.search)` 读入 `t.params`。已能对上行为的有：`autostart` 会 `game.start({skipIntro:true})`，`noaudio` 走静音音频，`q` 传给画质，`show` 命中 `gM` 的键时只搭展示场景。`gM` 的键是 `mats`、`level`、`backdrop`、`ground`、`fx`、`weapon`、`enemies`、`props`、`render`。

第一段 script 末尾会 `navigator.serviceWorker.register("/sw.js")`。`sw.js` 的缓存名是 `mason-3a-l3-v5`，网络失败才用缓存。画质档位存在 `saltline.settings.v1`，另外有 `mason.cache.l2` 和 `mason.cache.l3`。

未在上述锚点里出现的启动步骤，写「未证实」。
