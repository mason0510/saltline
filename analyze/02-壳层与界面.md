# 提示词：壳层与界面

只读 `index.html` 里两段 `<script>` 以外的部分，加上大包里拼进 `#ui` 的那段 HTML 模板。模板用锚点 `开始行动` 和 `data-act="deploy"` 定位。

请列出：

- 颜色token：`--ink`、`--bone`、`--signal`、`--steel`。不要另起一套色。
- 启动层 `#boot`：标题文字是 `mason`，进度条文案锚点是 `正在载入mason港区`。
- 标题页按钮的 `data-act`：`deploy`、`drill`、`settings`、`about`、`controls`。`drill` 若在当前文件里，记成「新手辅导」，不要猜它的玩法，玩法以任务循环那张卡为准。
- 链到页外的地址只记录已经写在标签上的 `href`。

画质、键位、敌人不要写在这张卡上。那些在另外的提示词里。
